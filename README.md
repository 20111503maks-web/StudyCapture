# StudyCapture

Android-приложение, которое превращает фото конспектов, доски и страниц учебника в
организованную учебную базу: **Capture → Understand → Organize → Learn → Review**.

> **Статус: v0.1, прототип MVP.** Код написан, ядро (FSRS, разбор структуры, конспект,
> карточки, поиск) покрыто unit-тестами. Android-приложение собирается в GitHub Actions;
> до проверки на реальном устройстве функции помечены в [ROADMAP.md](ROADMAP.md) как «ждёт проверки».

## Что умеет v0.1

- **Снять или импортировать**: сканер документов (края, перспектива, очистка), до 24 страниц;
  фото из галереи; вставка текста. Оригиналы всегда сохраняются.
- **Распознать**: ML Kit (латиница) + Tesseract (русский/кириллица) — прямо на телефоне.
- **Понять структуру**: заголовки, определения, формулы, списки, задания, таблицы.
  Сомнительные фрагменты подсвечиваются и **не исправляются автоматически**.
- **Организовать**: подсказка Предмет → Тема, которую вы подтверждаете.
- **Найти**: офлайн-поиск по всем страницам, понимает «где у меня было про митохондрии?».
- **Конспект**: собирается из предложений ваших страниц, каждый пункт ведёт к странице-источнику.
- **Карточки**: предлагаются автоматически, в повторение попадают только после одобрения.
- **Повторение**: алгоритм FSRS-6, ответы Again / Hard / Good / Easy, история ответов.
- **Приватность**: у приложения нет разрешения на интернет — само оно не может никуда отправить заметки.
  Сканер документов — компонент сервисов Google Play (по словам Google, обработка идёт на телефоне);
  если не хотите его использовать, загружайте фото. Удаление: страница, предмет, сгенерированные данные, всё.

### Про «бесплатный AI»

Весь «интеллект» v0.1 работает **на телефоне, бесплатно и без интернета**. Это детерминированный
движок (`core/understanding`): он выбирает и цитирует текст ваших страниц, но не пишет новых
предложений, поэтому не может «придумать» факты. Объяснения своими словами (Explain, Simplify)
требуют генеративной модели и появятся позже — как опциональная локальная модель. Подробно: [docs/adr/0001](docs/adr/0001-offline-first-free-ai.md).

## Как установить (без терминала)

- **Релиз (рекомендуется):** страница **Releases** → `StudyCapture-vX.Y.Z.apk`. Подписан постоянным ключом,
  поэтому новые версии ставятся поверх старой без потери данных.
- **Тестовая сборка:** вкладка **Actions** → последняя успешная **Build APK** → артефакт `StudyCapture-debug-apk`.
  Это debug-сборка: её подпись меняется от сборки к сборке (обновление = удаление и потеря данных),
  и она отлаживаемая. Только для проверки, не для настоящих конспектов.

Откройте APK на телефоне (Android 9+) и разрешите установку из этого источника.
Сканеру нужны сервисы Google Play; без них работает импорт фото.

Резервной копии нет намеренно (заметки приватны): при удалении приложения данные удаляются.

### Подпись релизов (один раз, владельцу репозитория)

1. Создайте ключ: `keytool -genkeypair -v -keystore release.jks -keyalg RSA -keysize 4096 -validity 10000 -alias studycapture`.
   Храните `release.jks` и пароли в надёжном месте — без них нельзя выпускать обновления.
2. В GitHub: Settings → Secrets and variables → Actions → добавьте `SIGNING_KEYSTORE_B64`
   (содержимое `base64 -w0 release.jks`), `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD`.
3. Создайте тег `v0.1.0` (Releases → Draft a new release → новый тег) — workflow «Release APK» опубликует APK.

## Для разработчиков

```bash
./gradlew :app:assembleDebug            # APK (нужен Android SDK)
./gradlew :core:srs:test :core:understanding:test

# Без Android SDK — только чистые Kotlin-модули:
cd tools/jvm-check && ../../gradlew test
```
