## v0.2 — стабилизация

- Пройти матрицу тестов на реальных фото (размытые, тёмные, наклонённые, рукопись, формулы, таблицы).
- Instrumented-тесты Room/FTS и конвейера; скриншот-тесты экранов.
- Фолбэк-камера на CameraX для устройств без Google Play services; ручная обрезка для фото из галереи.
- Мягкое удаление и журнал изменений (подготовка к синхронизации).

## Фаза 2

1. **PDF**: PdfRenderer постранично → тот же конвейер.
2. **Ask My Materials / смысловой поиск**: эмбеддинги чанков на устройстве, top-k + ответ со ссылками.
3. **Локальная LLM** (Gemma через LiteRT-LM, по желанию пользователя, отдельная загрузка модели):
   Explain / Simplify / Example / Step by step / Key points с метками происхождения.
4. **Quiz Mode**: Multiple choice, True/False, Short answer по одобренным материалам.
5. **Knowledge Gaps**: оценки по темам из истории повторений (с пояснением, что это не измерение знаний).

## Фаза 3+

- Аккаунт и синхронизация (собственный сервер; облачное удаление аккаунта).
- Сервер-шлюз для облачных моделей (ключи только на сервере, согласие на отправку фото).
- Windows-клиент на Compose Desktop, переиспользующий `core/*`.
- Выпуск в Google Play: подпись релиза, Data safety, политика конфиденциальности.
